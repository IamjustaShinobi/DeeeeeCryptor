CTF Toolkit runs every cipher/encoding decode locally in your browser — nothing you type is sent anywhere. The one exception: the optional Hashes.com lookup, which sends only the hash (never plaintext) to hashes.com using your own API key.

Select text on any page → right-click → "Decode with CTF Toolkit" to send it straight here.
